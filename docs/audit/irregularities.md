## Score-labeling policy

A numeric score is reported only when it is either (a) a local result labeled `HOLDOUT-DTI` with evaluator
version, withheld-positive count, and paired 95% CI, or (b) `ORGANIZER-CONFIRMED` with a copied
submission-page receipt. This checkout now contains (a): `evidence/cgrc_holdout_receipt.json`. It still
contains no (b) for any row; all board values are owner-recorded observations. Projections (e.g. the
MODEL range 0.10–0.19 for the new TIF) are never promoted into either category.

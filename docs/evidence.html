Evidence, irregularities, and the detection floor

Everything below is reproducible from bytes in this repository with bash scripts/run_all.sh. Nothing is asserted that was not measured.

1 · The metric, verified against the organizer's own example

scripts/gems_metric.py transcribes the organizer's equations verbatim. The published worked example on page 967 gives TPw = 3.00, FPw = 1.89, FNw = 2.00 and states 0.60. Our implementation computes 0.602652. Two algebraic identities also hold to machine precision:

FP_w = Σ_x p(x) − M     where M = Σ_x p(x)·max_g k(d(x,g))     (exact)
TP_w + FN_w = G                                                (exact)

Consequently, for unit-valued predictions,

DTI = T / ( 0.2·N + 0.8·G + 0.2·(T − M) )

with N the predicted positive cells, G the true cells, T the weighted credit. This single line governs every design decision in the repository.

2 · Irregularity: the holdout does not rank submissions

Finding. The proxy used across the sibling corpus — SGMC mapped faults more than 300 m from the catalogue — has Spearman ρ = −0.029 (p = 0.957, n = 6) against the public leaderboard, across every artefact for which both downloadable bytes and a published score exist.

Lift is each artefact's proxy DTI divided by a uniform-random dot field with the same number of dots. It removes the trivial advantage of mass: a blanket lattice covers a lot of a small truth set for free. The control makes the inversion sharper rather than softer — Hedge-v2 scores 0.46×, i.e. worse than random dots on the proxy, yet it scored 0.1563 on the real leaderboard, beating the lattice (0.0904) that the proxy puts first. A holdout on which a real submission ranks below random cannot be a promotion gate.

The artefact the proxy ranks best is the one the leaderboard ranks worst. Re-calibrating the proxy so its truth size matches the leaderboard-implied truth size (≈11.6 k cells, versus the proxy's 61,664) also fails to repair the ordering — the lattice stays first at every mass from 12 k to 62 k cells (ρ = +0.143, p = 0.787).

Mechanism. The proxy's truth is ≈5.3 × the leaderboard-implied truth, so the 0.8·G term dominates its denominator and the proxy over-rewards coverage while under-penalising mass. That is exactly the axis along which the corpus's candidates differ.

Consequence. Every promotion decision in the corpus that rests on this proxy — including the "+0.00487 live-mirror gain in 4/4 folds" quoted for the 0.2778 artefact — is unverified. This is flagged as an irregularity for review, not claimed as a disproof of any individual artefact.

3 · The requested power analysis: what can the holdout actually detect?

Cohen's framework, two-sided α = 0.05, power 0.80, so z1−α/2 + z1−β = 1.959964 + 0.841621 = 2.801585. The design is paired on withheld truth cells: two candidates are scored on the same holdout, so the observation is the per-cell credit difference dg. Then

minimum detectable total credit gap   ΔT_min = 2.801585 · σ_d · √n_eff
conversion to DTI (from the algebra)  dDTI/dT = s·(1 − 0.2·s) / T
sample size for a target gap         n = ( ΔT / (z · σ_d) )²

σ_d is measured from bytes, not assumed, and it dominates the answer because it depends entirely on how different the two candidates are:

Comparisonneffσ_dFloor, power 0.80
near-identical prune variants (d2.8 vs b2)12,4290.03390.00057 DTI
lattice vs dotted (distinct architectures)61,6220.31040.0117 DTI
this candidate vs lattice (distinct architectures)61,6440.46680.0176 DTI

Answer to the brief's question. To resolve a 0.0028 DTI gap at distinct-architecture noise you would need 296,457 informative withheld truth cells; the holdout supplies 12,429 — short by a factor of 24. Gaps of 0.0028, 0.0050, 0.0100 and 0.0200 are all inside the floor for the architecture comparisons the project ran, and the leaderboard-implied total hidden truth is only ≈11,583 cells, so no holdout built on this label set can ever supply enough positives. 0.0028 is noise being read as a ranking. The one regime where 0.0028 is nominally resolvable — near-identical inputs — is precisely the comparison whose ranking the holdout gets wrong, as §2 shows.

Also note the asymmetry the same arithmetic exposes: the proxies' n_eff counts only truth cells that at least one candidate reaches. Truth cells no candidate reaches are identical for both and cannot inform a difference — including them would inflate n and understate the floor.

Why this artefact is flagged circular. Its dots are placed on the SGMC raster, and the proxy's truth is built from that same raster, so its proxy DTI measures whether it reproduces its own input. The single-feature canary confirms it: the SGMC layer alone scores AUC = 0.998 against this truth, far above the 0.90 leakage cut, while the controls behave (uniform 0.500, distance-to-catalogue 0.514). There is therefore no valid holdout for this artefact, and its promotion rests on the metric algebra plus the leaderboard-verified pruning effect, not on a holdout score.

7 · Irregularities and negative results logged for review

  1. The mirrored "sample submission" is not a sample submission.
    The artefact published under the name sample_submission.tif — SHA-256 2176d08e485aa2cd2860ce8df539db4faf4d76163b38a4dd8c30a40454d35cbc, the very hash pinned as the "grid template" in the corpus's own external receipt — contains 60,988 positive cells in 0 / 1, cell-for-cell identical to the catalogue label mask. The organizer page states the sample "predicts total fault absence". Anyone who used it as a format template and as an all-zero baseline was silently emitting the catalogue. Nothing in this repository uses it; a copy is kept at data/grid/MIRROR_sample_submission_template.tif purely as evidence.
  2. The proxy cannot rank submissions (§2 above).
  3. Negative result: metric-optimal dot thinning loses credit.
    Thinning the incumbent's 37,654-dot set to a 300 m minimum separation kept 76.5 % of the dots but only 90.0 % of the credit, so the proxy DTI fell from 0.09397 to 0.08729. The cloud is not redundant — its credit comes from many well-separated dots — so "one dot per kernel width" is not a free mass saving on an existing emission. It is the right rule when emitting from scratch, which is what this submission does.
  4. The other holdout cannot be used either.
    The GEMSDOE50/data/grid/sample_submission.tif file in the sibling tree is byte-identical in content to that same catalogue mask, so it is not an all-zero control.
  5. The brief's "highest score" is stale.
    The brief states 0.3195 is the highest score. On 2026-10-08 the leaderboard shows rank 1 at 0.3774 and rank 7 at 0.3195. Targets should be set against 0.3774.

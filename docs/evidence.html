1 · The metric, verified against the organizer's own example

scripts/gems_metric.py transcribes the organizer's equations verbatim. The published worked example on page 967 gives TPw = 3.00, FPw = 1.89, FNw = 2.00 and states 0.60. Our implementation computes 0.602652. Two algebraic identities also hold to machine precision:

FP_w = Σ_x p(x) − M     where M = Σ_x p(x)·max_g k(d(x,g))     (exact)
TP_w + FN_w = G                                                (exact)

Consequently, for unit-valued predictions,

DTI = T / ( 0.2·N + 0.8·G + 0.2·(T − M) )

with N the predicted positive cells, G the true cells, T the weighted credit. This single line governs every design decision — the 300 m dot spacing, the 200 m catalogue exclusion, the break-even bar k > 0.2·DTI ≈ 0.052.

Cohen's framework (1988; two-sided α 0.05, power 0.80, z-sum 2.801585) on the compliant instrument:

Answer: a 0.0028 difference (e.g. the 0.2778 vs 0.2750 owner-recorded board gap) is distinguishable from noise when compared paired on whole-segment draws within one method family (2.0× the MDE); it is not a valid basis for ranking distinct architectures, whose paired variance is ~10× larger. Prior proxy-based numbers (ρ = −0.029 vs board values; mass-calibrated re-ranking ρ = +0.143, p = 0.787; thinning 0.09397→0.08729) are retained as the documented reason the SGMC proxy was retired as a ranking instrument.

4 · What drives the score (unchanged algebra, now with a measured truth-model cross-check)

Mass is taxed linearly0.2·N in the denominator. Same-family board rows 0.2600 @44,090 dots and 0.2778 @37,654 dots (owner-recorded, no receipts) — the 200 m prune deleted 6,436 sub-bar dots at constant credit.
Credit is a maximumTPw takes, per truth cell, the best prediction within the kernel; redundant dots add mass, not credit ⇒ one dot per 300 m.
Break-even barA dot earns only if its kernel credit k > 0.2·DTI ≈ 0.052 at the 0.26–0.28 operating point (measured 0.0548 on the corpus instrument; formula agrees).

6 · Irregularities and negative results logged for review

  1. The mirrored "sample submission" is not a sample submission.
    The artefact published under the name sample_submission.tif (SHA-256 2176d08e…4d35cbc) contains 60,988 positive cells in 0/1, cell-for-cell identical to the catalogue label mask; the organizer page states the sample "predicts total fault absence". Anyone using it as a format template and an all-zero baseline was silently emitting the catalogue. Nothing here uses it; a copy is kept at data/grid/MIRROR_sample_submission_template.tif as evidence.
  2. The SGMC proxy is not a holdout and cannot rank submissions — retired as a ranking instrument after the failed mass-calibrated re-ranking (ρ +0.143, p 0.787) and the circularity canary (0.9979 on its own truth; 0.5228 on withheld cells). This run replaced it with the compliant whole-segment instrument in §2.
  3. Negative result: metric-optimal dot thinning loses credit.
    Thinning the incumbent's 37,654-dot set to 300 m minimum separation kept 76.5 % of dots but 90.0 % of credit (proxy 0.09397→0.08729). The cloud is not redundant; "one dot per kernel width" is not a free saving on an existing emission.
  4. Negative result: 300 m catalogue exclusion collapses the relay mechanism.
    HOLDOUT-DTI 0.0753 → 0.0042 (1.5 km baseline). The first 300 m around every catalogue line are exactly where the off-catalogue truth model lives (σ 1.85 px ≈ 185 m around the surface). Operating band: 200–300 m. This supersedes the earlier 300 m exclusion decision.
  5. IR-54-021 · Continuation-direction bug (found pass-2, fixed).
    cgrc.continuation_lines re-oriented both segment ends to the same (arbitrary PCA-sign) direction, so continuation extended outward at only one end. Verified empirically; fixed (each end now extends outward; regression test added). The catalogue-truth proxy rewards less off-catalogue mass, so the pre-fix one-sided variant scored higher on the proxy (0.1091, 2.47×) than the corrected two-sided variant (0.0915, 1.50×) — the proxy's bias, not a better method. Pre-fix receipt retained at cgrc_holdout_receipt_v1_superseded.json.
  6. IR-54-016 · The literal lane gate is unsatisfiable against r11/r13/r14 by any submission.
    The minimum possible 3-px overlap with a raster equals its footprint coverage: r11 73.97 %, r13 99.87 %, r14 76.2 % — all above the 70 % limit, for any in-footprint prediction. The three registry rasters (greedy_mp, lattice_s5, union_tips10) are near-complete surface covers. Operational substitute applied (recorded): rank correlation against method rasters (max |ρ| 0.0422 < 0.90) and the closest non-vacuous 3-px overlap (0.5613 < 0.70). Flagged for owner/organizer clarification of the lane rule's intent.
  7. IR-54-017 · The problem page's null/NaN-outside-footprint text contradicts observed portal acceptance.
    The page requires null/NaN outside the footprint, yet the corpus-best 0.2778 file is all-finite with no nodata tag, and the user's "Predicted values must be in range [0, 1]" error is produced by exactly those out-of-range encodings. Empirically the all-finite [0,1] file uploads (that is the 0.2778 file). Both statements are recorded; the formal spec remains the page text.
  8. IR-54-018 · The standing prompt's "0.3195 is the current top" is stale.
    Live fetch of the public leaderboard (2026-10-08): top = 0.3774 (rank 1, 13 submissions), 0.3195 sits at rank 7 (DARD). Snapshot: docs/data/leaderboard-snapshot.json. No submission-page receipts; no TIFF-to-row attribution asserted.

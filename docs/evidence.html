1 · The metric, verified against the organizer's own example

scripts/gems_metric.py transcribes the organizer's equations verbatim. The published worked example on page 967 gives TPw = 3.00, FPw = 1.89, FNw = 2.00 and states 0.60. Our implementation computes 0.602652. Two algebraic identities also hold to machine precision:

FP_w = Σ_x p(x) − M     where M = Σ_x p(x)·max_g k(d(x,g))     (exact)
TP_w + FN_w = G                                                (exact)

Consequently, for unit-valued predictions,

DTI = T / ( 0.2·N + 0.8·G + 0.2·(T − M) )

with N the predicted positive cells, G the true cells, T the weighted credit. This single line governs every design decision in the repository.

Mechanism hypothesis. The proxy's truth is about 5.3 times the model-implied truth, so the 0.8·G term could cause this proxy to over-reward coverage and under-penalise mass. This hypothesis is a reason not to use the proxy for candidate ranking, not proof about hidden expert labels.

Consequence. Every promotion decision in the corpus that rests on this proxy — including the "+0.00487 live-mirror gain in 4/4 folds" quoted for the 0.2778 artefact — is unverified. This is flagged as an irregularity for review, not claimed as a disproof of any individual artefact.

3 · Proxy sensitivity illustration — not hidden-label holdout power

The prior calculation used SGMC-derived proxy truth and therefore does not meet the required whole-segment hide-and-recover design. The formula below is a conditional PROXY-SENSITIVITY / MODEL calculation, not a valid power analysis for the competition's hidden labels or a HOLDOUT-DTI result. Cohen's framework used two-sided α = 0.05 and nominal power 0.80; its z-sum was 2.801585. For this exploratory paired proxy comparison, the observation is the per-cell proxy-credit difference dg. Then

minimum detectable total credit gap   ΔT_min = 2.801585 · σ_d · √n_eff
conversion to DTI (from the algebra)  dDTI/dT = s·(1 − 0.2·s) / T
sample size for a target gap         n = ( ΔT / (z · σ_d) )²

σ_d was measured from raster bytes for this proxy comparison. The values below are conditional proxy diagnostics only; they do not estimate the detection floor for hidden expert labels:

6 · Irregularities and negative results logged for review

  1. The mirrored "sample submission" is not a sample submission.
    The artefact published under the name sample_submission.tif — SHA-256 2176d08e485aa2cd2860ce8df539db4faf4d76163b38a4dd8c30a40454d35cbc, the very hash pinned as the "grid template" in the corpus's own external receipt — contains 60,988 positive cells in 0 / 1, cell-for-cell identical to the catalogue label mask. The organizer page states the sample "predicts total fault absence". Anyone who used it as a format template and as an all-zero baseline was silently emitting the catalogue. Nothing in this repository uses it; a copy is kept at data/grid/MIRROR_sample_submission_template.tif purely as evidence.
  2. The SGMC proxy is not a holdout and cannot rank submissions (§2 above); the small exploratory comparison uses unreceipted owner-recorded board observations.
  3. Negative result: metric-optimal dot thinning loses credit.
    Thinning the incumbent's 37,654-dot set to a 300 m minimum separation kept 76.5 % of the dots but only 90.0 % of the credit, so the proxy DTI fell from 0.09397 to 0.08729. The cloud is not redundant — its credit comes from many well-separated dots — so "one dot per kernel width" is not a free mass saving on an existing emission. It is the right rule when emitting from scratch, which is what this submission does.
  4. A sibling sample raster is not an all-zero control.
    The GEMSDOE50/data/grid/sample_submission.tif file in the sibling tree was reported byte-identical in content to the catalogue mask; it is not an admissible zero-control template and was not used in this audit.
  5. Historical board comparison lacks submission-page receipts.
    A prior owner-recorded snapshot lists rank 1 as 0.3774 and rank 7 as 0.3195. This audit pass did not obtain receipts, so neither value is treated as ORGANIZER-CONFIRMED and no target or weekly slot is selected.

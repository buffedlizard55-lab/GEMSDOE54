1 · H54-A — State-map under-map complement IMPLEMENTED

LayersUSGS State Geologic Map Compilation fault layers for Nevada and California (NV.zip, CA.zip, public domain) rasterised to the competition grid; the organizer catalogue (data/grid/labels.tif) used only as an exclusion mask.
Physical signatureProvenance, then geometry. The signature is not a spectral or morphometric transform but a source-level difference: a fault that one authoritative compilation carries and another does not. Geometry is then used as a quality gate — an orientation-invariant principal-axis eigenvalue ratio (λ₁/λ₂ ≥ 6) plus a minimum principal extent of 5 cells, which keeps trace-like components and rejects blobs and stray line work.
Why it catches catalogue-missing faultsThe organizers define their new labels as faults "not contained within the current public USGS database". The state map packages are a different product with different compilers, so a fault present in the state compilation and absent from the catalogue satisfies that definition by construction. The catalogue holds 60,988 cells; the state compilation holds 82,151; 61,664 of those lie more than 300 m from any catalogue cell.
How it differs from prior workPrior work treated SGMC as one input among many and pruned within 200 m of the catalogue. This candidate (a) excludes the full 300 m kernel, so that no emitted dot can be earning credit from a catalogued fault; (b) replaces bounding-box elongation — which is orientation-dependent and rejects a 45° line — with the PCA eigenvalue ratio; and (c) derives the dot spacing from the metric's mass/credit algebra rather than from a fixed rule.
Legacy model projection (not a result)The prior build receipt records 15,907 emitted dots versus an owner-recorded, unreceipted family count of 37,654. The old ≈12 % threshold and ≈13 % comparator are model estimates only; neither is HOLDOUT-DTI or ORGANIZER-CONFIRMED, and this audit does not select or promote H54-A.
CostLOW — implemented, runs in seconds on CPU.
Validation statusCANNOT BE VALIDATED ON THE EXISTING PROXY The SGMC-derived proxy target is built from the same SGMC raster, so the historical PROXY-CANARY returns AUC = 0.997948 by construction. The submission's PROXY-DTI of 0.551333 is a self-consistency diagnostic only; neither number is a compliant holdout result or a score. New external data is needed to test it honestly — specifically an independent fault compilation that is not SGMC and not the catalogue.

2 · H54-B — Quaternary viability gate on state-map faults NOT RUN

LayersSGMC faults (as H54-A) intersected with: the GDR-mapped spring and well inventory already mirrored in the corpus (gdr_wellspring_in_footprint.csv, 27,092 rows, carrying temp_c, geotherm*_c and a dist_known_fault_px attribute), the volcanic-vent raster, and — only if the rights question is closed, see below — ComCat hypocentres.
Physical signatureYoung-expression conjunction. State compilations carry faults of all ages, and pre-Quaternary faults carry no scarp, so they are not in the experts' label set. A fault that hosts a thermal spring, aligns with a chain of springs, or cuts young volcanics is demonstrably young. The signature is a spatial conjunction: fault trace ∧ (spring/vent within k cells), with an optional along-strike alignment test across ≥ 3 points.
Why it catches catalogue-missing faultsThe gate is applied inside the already-excluded complement, so by construction it can only ever select non-catalogue faults; its job is purely to raise precision by removing the pre-Quaternary members of that complement.
How it differs from prior workThe corpus's H53-A applied a probe/TMI point-lineation rule and accepted 0 of 145 clusters under its frozen thresholds, failing before emission. This candidate gates per trace rather than requiring cluster alignment, which is a far weaker and more robust requirement, and it exploits the wells' own recorded distance-to-known-fault field instead of recomputing proximity.
Expected benefitPrecision, not recall: a smaller, cleaner dot set at roughly constant credit, which is exactly the direction the algebra rewards.
CostMEDIUM — one afternoon; the CSV is already local.
Data checkThese files are not present in the current checkout. The paths and licence wording come from prior sibling-repository notes and have not been reverified here; do not assume availability or redistribution permission. ComCat rights remain unresolved and it must not be used until checked.

3 · H54-C — Catalogue topology: relay ramps and along-strike completion NOT RUN

LayersCatalogue fault vectors only — gdr_qfaults_traces.csv (126,177 bytes, already mirrored). No external data required.
Physical signatureGraph and azimuth geometry. Fit the trace graph's azimuth clusters; extrapolate each trace beyond its mapped tips; find step-overs and relay zones between near-collinear adjacent traces and bridge them; project the conjugate dip direction where the basin-margin asymmetry implies an unmapped counterpart.
Why it catches catalogue-missing faultsExpert completion of a Basin-and-Range fault map routinely fills exactly these gaps — the relay ramp between two en-echelon strands, and the short along-strike continuation past a mapped tip. Those additions are geometrically implied by the catalogue but absent from it, which is the organizers' definition of a new label. Predicted positions are explicitly beyond the mapped trace, so they cannot be scoring the catalogue back to itself.
How it differs from prior workEarlier tip and step-over candidates (H32a, H33d, r7-nms3-dem10-scarp) emitted from raster morphology of a derived field. This one works on the vector trace graph, so geometry is exact rather than approximated by a 100 m rasterisation, and it enforces the mass budget from the algebra.
Expected benefitModerate recall gain at low mass; the strongest candidate that is fully unblocked and uses no new external data.
CostLOW–MEDIUM — the vector file is local; the geometry code is the only new work.
Data checkObtainable now: file present at GEMSDOE48/data/raw/external/gdr_qfaults_traces.csv, licence CC BY 4.0 per the sibling receipt.

4 · H54-D — 1 m lidar scarp morphometry BLOCKED

LayersThe 1 m DEM tiles listed in the competition's own 1m_DEM_links.csv, i.e. USGS 3DEP lidar elevation.
Physical signatureCurvature / Hessian scarp detection. Quaternary fault scarps in the Great Basin are typically 1–5 m high and 10–30 m wide: a tenth of a pixel at 10 m resolution, but 10–30 cells at 1 m. The transform is a profile-curvature filter (second derivative of elevation across the scarp) followed by an along-strike lineament trace.
Why it catches catalogue-missing faultsThe catalogue was compiled largely from aerial photography and 10 m DEMs, on which a 1–5 m scarp is marginal. The organizers publish 1 m DEM links inside the competition data because that is the resolution at which the newly labelled faults are visible — the experts' new labels and this layer share a physical basis.
How it differs from prior workCorpus DEM work used 2 m and 3 m pilots over a handful of tiles (data/pilot/dem3m/ holds two tiles). A full 1 m curvature-plus-Hough pass over the lidar-covered portion of the study area has not been run.
Expected benefitHighest scientific upside of the five: it is the only candidate that adds information the catalogue's compilers never had.
CostHIGH — tile downloads and roughly 1010 cells of filtering.
Data checkNOT OBTAINABLE IN THIS SESSION. 1m_DEM_links.csv sits behind the DrivenData login on the data page, no reachable mirror of the link list exists in any sibling repository, and the Dropbox mirror of the derived PDF of those links returns HTTP 000 from this sandbox. The named free official source is USGS 3DEP / The National Map (usgs.gov/3d-elevation-program, public domain), which is obtainable on any machine with unrestricted network access — but the specific tile list the organizers curated is not, so the candidate is not viable here.

5 · H54-E — Bedrock / alluvium range-front contact lineaments BLOCKED

LayersA DEM (1 m preferred, 10 m workable) plus, optionally, the SGMC polygon geology to locate the contact directly.
Physical signatureContact-lineament detection. Smooth the elevation field, then detect the lineament along the bedrock/alluvium boundary from its planform sinuosity and its transverse curvature, and flag range fronts with no catalogued fault within 300 m.
Why it catches catalogue-missing faultsThe range-front fault is the dominant Quaternary structure in the Basin and Range; a range front whose fault is unmapped is a candidate by definition, and the prediction is anchored to a boundary that is independent of the catalogue.
How it differs from prior workThe corpus's ctx-ridge and topo-gap-closure candidates used ridge statistics and gap statistics of a raster field. This candidate instead segments the geologic contact and characterizes its geometry.
Expected benefitModerate; largely overlapping in mechanism with H54-D but at coarser resolution.
CostHIGH and blocked on the same missing DEM list as H54-D.
Data checkBlocked identically to H54-D. Deprioritised in favour of H54-D, which subsumes it at better resolution.

The problem, in four sentences

The competition asks for a fault-probability GeoTIFF over the GeoDAWN study area in western Nevada. Scoring uses a distance-weighted Tversky index with α = 0.2 (false positives), β = 0.8 (false negatives) and a triangular 300 m kernel, and — crucially — the ground truth is only the faults that are missing from the public catalogue, which geology experts at NLR and USGS identified by hand. Every cell you mark pays a small linear false-positive tax, while every truth cell you miss costs four times as much, so the achievable score is set by how precisely you can place a small number of confident predictions. The public leaderboard fetched 2026-10-08 displayed 0.3774 at rank 1, 0.3195 at rank 7, and 0.2778 at rank 13. These are PUBLIC-LEADERBOARD SNAPSHOT observations, not copied submission-page receipts; no rank-to-TIFF attribution is established and none is used to select a target or slot. Snapshot details.

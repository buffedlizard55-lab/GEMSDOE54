The problem, in four sentences

The competition asks for a fault-probability GeoTIFF over the GeoDAWN study area in western Nevada. Scoring uses a distance-weighted Tversky index with α = 0.2 (false positives), β = 0.8 (false negatives) and a triangular 300 m kernel, and — crucially — the ground truth is only the faults that are missing from the public catalogue, which geology experts at NLR and USGS identified by hand. Every cell you mark pays a small linear false-positive tax, while every truth cell you miss costs four times as much, so the achievable score is set by how precisely you can place a small number of confident predictions. A prior repository record lists 0.3774 and 0.2778 as board observations, but this audit pass has no submission-page receipts; they are not ORGANIZER-CONFIRMED scores and are not used to select a target or weekly slot.

If a file is approved in future, the steps are

  1. Check the approval. The file's run card must show ok_to_submit: true and a HOLDOUT-DTI with a CI. This repository has none today.
  2. Download the approved file and confirm its SHA-256 matches the run card. If it differs, do not upload it.
  3. Sign in to DrivenData and open the GEMS competition's Submissions area. The competition data page requires a login (verified: redirect to login); no authenticated download was made in this pass.
  4. Upload one single-band GeoTIFF (.tif) directly. Do not zip or re-encode it unless the form requires it.
  5. Optional note (max 140 characters): GEMSDOE54 undercomplement-q200: SGMC state-map complement of catalogue, d>300m, linearity gate, 200m dots (105 characters). This is a draft; a future approved file will need its own note.
  6. Submit, then record the receipt. Only a number copied from the submission page counts as ORGANIZER-CONFIRMED. Record it in registry/submissions.json. Until then it stays unscored.

What this artefact is

A unit-valued dot set, not a probability field. Dots are placed on USGS State Geologic Map Compilation faults that lie more than 300 m from the competition catalogue, filtered to trace-like shapes, and thinned so that no two dots are closer than 200 m. The rationale, the algebra and the falsifiable prediction are on the Evidence page.

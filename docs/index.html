What the file is

A visible-only gradient-boosted classifier. For this file it is trained on all catalogued faults against the remaining footprint cells (the holdout retrains it per fold, using only the faults each fold can see). Inputs are the 19 owner-bridge feature bands plus gradient magnitudes of five geophysical bands. The top 3 % of admissible cells are kept, then thinned to 200 m dots by the builder's linearity gate. Cells within 300 m of a catalogued fault are excluded. Its holdout score is tied with the SGMC complement that a sibling repository already publishes (GEMSDOE3 gapfinder-v2-sgmc-gap, IR-54-045), and it does not beat it.

Feature provenance is owner-claimed (hash-matched to the owner's pin, not organizer-authenticated). Labels are the owner-mirrored catalogue. See the audit ledger.

What would change the answer

  • A candidate that beats 0.0483 on the same evaluator with a paired CI above zero and passes the literal lane rule against the full sibling set. The 110 non-dense overlaps are real, so a different lane is needed, not just a different threshold. The dense-raster degeneracy is in IR-54-057.
  • An organizer ruling on the lane rule and on whether known faults are scored (IR-54-051).
  • Organizer confirmation of the "[0, 1]" validator message on a test upload, which we could not reproduce from the sandbox (IR-54-055).

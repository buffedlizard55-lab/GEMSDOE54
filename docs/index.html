The problem, in four sentences

The competition asks for a fault-probability GeoTIFF over the GeoDAWN study area in western Nevada. Scoring uses a distance-weighted Tversky index with α = 0.2 (false positives), β = 0.8 (false negatives) and a triangular 300 m kernel, and — crucially — the ground truth is only the faults that are missing from the public catalogue, which geology experts at NLR and USGS identified by hand. Every cell you mark pays a small linear false-positive tax (0.2), while every truth cell you miss costs four times as much (0.8), so the achievable score is set by how precisely you can place a small number of confident predictions. The public leaderboard fetched live on 2026-10-08 displays 0.3774 at rank 1, 0.3345 at rank 2, 0.3262 at rank 3, 0.3195 at rank 7, and 0.2778 at rank 13 — PUBLIC-LEADERBOARD SNAPSHOT observations, not copied submission-page receipts; no rank-to-TIFF attribution is established. Why the earlier upload failed with “Predicted values must be in range [0, 1]” — and why this file can’t. The portal rejects (a) any value read outside [0,1] — e.g. a float32 nodata sentinel such as −3.4028234663852886e+38 from training_features.tif — and (b) rasters whose nodata tag is a large-negative sentinel or NaN, because the sentinel itself is not a value in [0,1]. GEMSDOE32 measured both mechanisms on the live portal; the file that scored 0.2778 is exactly this file’s byte class: single-band float32, no nodata tag, every one of the 12,279,160 cells finite, min 0.0 max 1.0. The validator receipt for this file: evidence/cgrc_submission_receipt.json.

Why the corpus best is 0.2778 — and what it takes to go higher

The 0.2778 artefact (h33-h33-2-b2, registry copy dotted_b2_prune_02778.tif) won by mass pruning on a validated surface: it is the 0.2708 dotted base with every dot inside 200 m of the catalogue deleted (44,090 → 37,654 dots). Under the metric’s exact algebra, for unit-valued dots DTI = T / (0.2·N + 0.8·G + 0.2·(T − M)): each dot costs 0.2 of denominator mass, credit is a per-truth-cell maximum (redundant dots add mass, not credit), and a dot earns only if it clears the break-even bar k > 0.2·DTI ≈ 0.052–0.055. Dots hugging the catalogue sit on ground the hidden truth is defined to exclude, so they were pure tax — deleting them bought +0.0178. The public top (0.3774) implies ≈25% higher credit-per-dot at similar mass: a better detector of the off-catalogue set (full Geodawn feature stack, DEM scarps, trained models), not a thinner version of the same dots. Full derivation: research/why-h33.md.

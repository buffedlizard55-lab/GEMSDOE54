Prerequisite

Power and the DTI detection floor

What must be measured

For a paired candidate-versus-baseline comparison, Cohen's d is a standardized difference. Its minimum detectable value depends on the independent sample count and the variability of paired differences. A raw pooled-DTI floor additionally depends on the observed cluster-bootstrap uncertainty.

Fault pixels within a segment are not independent. Use whole held-out fault segments as the resampling units; do not substitute generic spatial blocks. Recompute pooled DTI inside each paired whole-segment bootstrap draw. Report the withheld-positive count as context, not as the number of independent experiments.

The power CLI requires a frozen receipt specifying whole-segment hiding with buffer, visible-only catalogue-derived features, pixel-exact visible masking, pooled DTI, the triangular 300 m kernel, and bootstrap draws. Without that receipt, it refuses to produce a floor.

Canary before trust

Feature-alone leakage checks

Evaluate each feature by itself on the same frozen whole-fault-segment hide-and-recover holdout before trusting any composite. An AUC above 0.90 is treated as a leakage canary until the feature derivation, mask, segment folds, and target independence are audited. The threshold is a trigger for investigation, not proof of leakage on its own.

Every catalogue-derived surface must be rebuilt from the visible catalogue for each fold; a precomputed distance-to-full-catalogue layer leaks held-out geometry. Use the exact pixel-level visible-fault mask before scoring.

Prior H54-A leakage canary (PROXY, not HOLDOUT-DTI): the SGMC raster used to build the candidate scored AUC 0.997948 against a proxy truth built from the same SGMC layer; the uniform control scored 0.5. This is a circularity/leakage finding, not evidence of fault-prediction skill. No feature-alone canary was run on a compliant whole-segment holdout in this audit pass. See leakage receipt.

Parallel-lane gate

Duplicate detection is a hard stop

Before placement and after the final raster write, compare decoded prediction pixels—not TIFF bytes, compression, or filenames—with every accessible registry raster. Stop and record a duplicate if rank-correlation exceeds 0.90 or more than 70% of candidate dots are within 3 pixels of one prior raster's dots.

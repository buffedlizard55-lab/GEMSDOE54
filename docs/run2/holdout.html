Whole-segment holdout — evaluator gemsdoe54-segment-cv v2

Label: HOLDOUT-DTI. These are catalogue-recovery numbers, not hidden-test numbers. Receipt: evidence/holdout_segment_cv_run2_variant.json (v1 receipt for C0–C3: v1, reproduced exactly).

Design

  • Units: 3,199 eight-connected catalogue segments, 5 folds of 639–640 segments.
  • Withheld positives: 60,988 catalogue cells (11,665 to 13,171 per fold). A 300 m collar is removed from both training and scoring.
  • Metric: organizer distance-weighted Tversky, α = 0.2, β = 0.8, 300 m triangular kernel. Cross-checked against the grid implementation on fold 0.
  • Inference: paired whole-segment cluster bootstrap, 1,000 replicates, same resample for every candidate. Null: 30 torus shifts of C1.
  • Leakage canary: single-feature AUC of every band, plus the learned model's own output. Threshold 0.90.
  • Limitation: the target is the USGS catalogue, while the scored hidden set is new faults outside it (IR-54-083).

Leakage canary

Learned-model AUC, max over folds: 0.822 (threshold 0.90: clear). Single-feature maxima: 0.594 (ieq_n100a15), 0.591 (geod_2ndinv). Distance to visible catalogue: 0.756 (a withholding artefact, reported separately). SGMC layer: 0.526. No feature is flagged.

What this does and does not show

  • A learned model trained only on visible catalogue faults recovers withheld catalogue faults about as well as the SGMC complement. It is not better.
  • The SGMC complement is the family that sibling repositories already occupy, so the holdout cannot clear a unique file in that family.
  • The geophysical single-family ridges (C5, C6) are not better than chance or the magnetic ridge.
  • None of this measures new-fault skill. The organizer's hidden set is outside the catalogue. Board values remain BOARD-UNVERIFIED.

Feature bands come from the owner bridge, hash-matched to the owner's pin and not organizer-authenticated. Run card: data/run-card.json.

Checks a file must pass before upload

  • sha256 matches the run card; a rebuild gives identical bytes.
  • Single band, float32, EPSG:32611, 100 m, same bounds as the training data.
  • In-footprint values are finite and within [0, 1]. No sentinel values (IR-54-017).
  • Outside-footprint encoding matches the chosen reading (D2).
  • Copy check: no exact or decoded match outside the repository.
  • Rank correlation at most 0.90 against every raster, using absolute values.
  • Lane check passes under the chosen reading (D1).

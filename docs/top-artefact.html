Why H33-2-B2 scored 0.2778, and whether 0.2778 can be beaten

Short answer. The mechanism is algebraically sound and verified on a synthetic grid. The 0.2778 value itself has no organizer receipt, and the owner's own audit is internally inconsistent. Beating 0.2778 is possible in principle. Nothing in this repository establishes it.

Learning only. This artefact is another team's file. Under Appendix A.5(1) a submission must be the competitor's original work, so this file must not be submitted. The registry in this repository holds a byte-identical copy for lane checks only (IR-54-015).

2. The algebra (ALGEBRA-CHECKED)

The organizer's definitions for unit-valued dots (DrivenData metric page, quoted in the repository's metric notes): TPw = Σg maxx k(d(x,g)); FPw = Σx [1 − maxg k(d(x,g))]; FNw = Σg [1 − maxx k(d(x,g))]; DTI = TPw / (TPw + 0.2·FPw + 0.8·FNw); k(d) = max(1 − d/300 m, 0).

Lemma. Deleting a dot x whose kernel mass mx = maxg k(d(x,g)) is zero changes neither TPw nor FNw, and lowers FPw by exactly 1. Therefore DTI rises to T / (T + 0.2(FPw − k) + 0.8·FNw), where k is the number of deleted zero-credit dots.

Check. tests/test_segment_cv.py::test_deleting_zero_credit_dots_only_changes_fp and scripts/top_artefact_analysis.py reproduce this on a synthetic grid. TP and FN are unchanged, the FP drop equals the deleted count (28 of 28), and the closed form matches the grid metric to 10−9.

Limit of the lemma. If a deleted dot has mx > 0, its removal can also lower TPw, so the net effect is ambiguous. The observed increase is consistent with the deleted dots having little or no hidden-truth credit, but it does not prove that.

3. What the two board values imply (MODEL, conditional)

Solving the identity above for the credited truth mass T, using only the two board values and k = 2,545 (assuming every deleted dot earned zero credit and both board values are exact):

T = 0.2·k / (1/0.2708 − 1/0.2778) ≈ 5,470 credited cells. The denominator at the parent, 0.2·FPw + 0.8·FNw ≈ 14,730.

If only a fraction f of the deleted dots had zero credit, the implied T scales with f: f = 0.9 gives 4,923; f = 0.75 gives 4,103; f = 0.5 gives 2,735. The sensitivity shows that the inference is fragile to the zero-credit assumption. Treat T as a model quantity, not a measurement.

4. Why it scored where it did (ranked, with the evidence for each)

a. The parent already had credit per dot

The 0.2708 parent carries 40,199 dots and scores 0.2708 on the board (user-reported). Its precision is the starting point. Pruning can only raise the score when it removes dots that earn no credit, so the parent had to be credit-dense before pruning.

Evidence class: BOARD-UNVERIFIED for the score; REGISTRY-VERIFIED for the count.

b. The pruned dots were close to the catalogue

All 2,545 deleted dots lie within 200 m of the published catalogue. The hidden expert set is by construction absent from that catalogue, so dots hugging catalogue traces are plausibly the least likely to earn hidden-truth credit. This is a hypothesis, not a result: a deleted dot that lies within 300 m of a hidden fault would have earned credit.

Evidence class: OWNER-RECORDED geometry; credit is not observed.

c. The reported gain exceeds the owner's own projection

The reported gain is 0.2778 − 0.2708 = 0.0070. The owner's recorded live-mirror gain is +0.00487, and the owner's projection is 0.27467. The reported value is 0.0031 above the owner's projection. Either the organizer split behaves differently from the owner's mirror, or the owner's calibration is off. The owner's file does not resolve which.

Evidence class: BOARD-UNVERIFIED versus OWNER-RECORDED.

6. Can a submission score above 0.2778?

In principle, yes. DTI is bounded above by 1. Removing dots that provably earn no credit can only raise it, and a method can raise it by earning more credit per dot. Nothing in the metric caps the score at 0.2778.

Not established by any evidence here. Three obstacles stand in the way.

  1. Zero-credit is unobservable on the hidden set. Further pruning risks deleting credited dots, and every credited dot lost lowers TPw.
  2. Our holdout is not the organizer's test set. It recovers catalogue faults, which are better mapped than the newly identified faults in the hidden set. Its DTI values are on a different truth set and cannot be compared with the board. The best-performing candidate here (C1, the H54-A rule) scores far below 0.2778 on the holdout, so the holdout cannot say whether it would exceed 0.2778 on the hidden set.
  3. The top artefact cannot be re-evaluated here. Its prune uses the full published catalogue, and its parent emission is not reproducible from the inputs in this repository. It is therefore not a holdout candidate.

Verdict on achievability. A score above 0.2778 is achievable only if a method earns more credited hidden-truth mass per dot than the parent. This repository has no receipt that shows that, and the only organizer-grade test is a submission. Whether to spend a slot is a decision for the user. This page does not make it.
